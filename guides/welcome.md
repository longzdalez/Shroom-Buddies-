# Welcome 🍄

This is your guides section. Each guide is a simple text file in the `guides` folder.

## How to add a guide
1. Write your guide as a `.md` file and put it in the `guides` folder
2. Add a line for it in `guides/guides.json`
3. Optional: add a picture to `backgrounds` and set `"image"` to its path

**Tip:** you can use `#` for headings, `**bold**`, `*italic*` and `-` for lists.
